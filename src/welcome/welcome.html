HOW IT WORKS
Three things to know. None of them require your attention again.
01
It runs silently
No toast, no popup, no badge. The banner is gone before you'd have noticed it. Quiet is the whole product.
02
Look for the mark
Krumb lives in the Chrome toolbar. Click it to see what happened on the current page, pause it for one site, or open settings.
03
Help the next person
If a site sneaks past Krumb, click the toolbar and "report it". That opens a pre-filled GitHub issue. The fix lands for everyone on the next daily sync.
Yes, Krumb has access to every site you visit.

That permission is non-negotiable for a cookie blocker — banners are on every site, so we have to be there too. But Krumb only ever looks for banner DOM elements and clicks them. It doesn't read page content, doesn't store URLs, doesn't phone home. The selector list is fetched directly from GitHub.
